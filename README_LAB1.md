## Step 1: Run an IID FL Experiment on Adult

The IID Adult setup uses:

- [exp-adult.yaml](c:/Users/maiaj/Documents/INSA-LYON/25-26/Semester2/fl-lab/config/exp-adult.yaml)
- [fedavg-adult-logreg.yaml](c:/Users/maiaj/Documents/INSA-LYON/25-26/Semester2/fl-lab/config/fedavg-adult-logreg.yaml)
- [fedavg-adult-mlp.yaml](c:/Users/maiaj/Documents/INSA-LYON/25-26/Semester2/fl-lab/config/fedavg-adult-mlp.yaml)

This config uses:

- `dataset.name: adult`
- `distribution.name: iid`
- `n_clients: 10`
- `n_rounds: 50`

Run Adult IID with FedAvg:

```bash
fluke federation config/exp-adult.yaml config/fedavg-adult-logreg.yaml
fluke federation config/exp-adult.yaml config/fedavg-adult-mlp.yaml
```

To compare with decentralized Adult IID runs:

```bash
fluke decentralized config/exp-adult.yaml config/decentralized_fedavg_adult-logreg.yaml
fluke decentralized config/exp-adult.yaml config/decentralized_fedavg_adult-mlp.yaml
```

## Step 6: Apply SCAFFOLD and Compare It with FedAvg

This comparison is done with federated learning runs, not decentralized peer-to-peer runs.

Relevant method configs:

- [scaffold-adult-logreg.yaml](c:/Users/maiaj/Documents/INSA-LYON/25-26/Semester2/fl-lab/config/scaffold-adult-logreg.yaml)
- [scaffold-adult-mlp.yaml](c:/Users/maiaj/Documents/INSA-LYON/25-26/Semester2/fl-lab/config/scaffold-adult-mlp.yaml)

### Single-run examples

```bash
fluke federation config/exp-adult-noniid.yaml config/fedavg-adult-logreg.yaml
fluke federation config/exp-adult-noniid.yaml config/scaffold-adult-logreg.yaml

fluke federation config/exp-adult-noniid.yaml config/fedavg-adult-mlp.yaml
fluke federation config/exp-adult-noniid.yaml config/scaffold-adult-mlp.yaml
```

### Full comparison sweep

Script:

- [run_adult_noniid_method_grid.py](c:/Users/maiaj/Documents/INSA-LYON/25-26/Semester2/fl-lab/runs/run_adult_noniid_method_grid.py)

Run:

```bash
python runs/run_adult_noniid_method_grid.py
```

Useful filtered runs:

```bash
python runs/run_adult_noniid_method_grid.py --methods FedAvg SCAFFOLD --models LogReg
python runs/run_adult_noniid_method_grid.py --methods SCAFFOLD --models MLP --batch-size 64 --local-epochs 5 --client-pct 100
python runs/run_adult_noniid_method_grid.py --dry-run
```

Outputs are written under:

- `runs/adult_noniid_methods/FedAvg`
- `runs/adult_noniid_methods/SCAFFOLD`

Then generate the comparison figures:

```bash
python runs/generate_method_comparisons.py
```
